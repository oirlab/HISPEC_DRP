=================================================
Saturated detector Flatfield Calibration Pipeline
=================================================

Overview
--------
**Input:** Raw UTR data.

**Cal. Outputs:** saturation and non-linearity correction calibrations.

**Other Output:** Rate map in e-/s (Level 0).

Calibration pipeline to generate saturation and non-linearity correction calibration files from raw saturated flat UTR data.
Also creates level 0 rate map data products for each flat exposure processed.
