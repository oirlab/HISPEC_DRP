Stage 0
=======

Overview
--------
**Input:** Raw UTR data.

**Output:** Rate map in e-/s (Level 0).

The stage 0 pipeline converts raw data (UTR ramp) into level 0 (rate map) data, applying all detector-level corrections/calibrations.

Significant heritage from JWST and Roman was leveraged.
E.g. https://jwst-docs.stsci.edu/jwst-science-calibration-pipeline/stages-of-jwst-data-processing/calwebb_detector1#gsc.tab=0
