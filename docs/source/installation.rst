Installation
============

1. Clone the repository:

.. code-block:: bash

    git clone https://github.com/oirlab/HISPEC_DRP

2. Create and activate a virtual environment with Python 3.11 (conda not required but recommended):

.. code-block:: bash

    conda create -n "hispec_drp_env" python=3.11
    conda activate hispec_drp_env

3. Install live version with pip:

.. code-block:: bash

   cd HISPEC_DRP
   pip install -e .
