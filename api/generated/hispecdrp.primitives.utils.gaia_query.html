get_2mass_data_vizier(ra, dec, radius_arcsec=3.0)[source]

Cone-search the 2MASS PSC on VizieR (II/246) and return the nearest source.

Uses the same VizieR mirror fallback as the Gaia DR3 queries. The returned dict uses the same key names as get_2mass_from_gaia() (twomass_id, tm_ra, tm_dec, j_m, j_msigcom, h_m, h_msigcom, ks_m, ks_msigcom). 2MASS JHKs magnitudes are in the Vega system.

Parameters:

  • ra (float) – ICRS coordinates in degrees (e.g. the Gaia source position).

  • dec (float) – ICRS coordinates in degrees (e.g. the Gaia source position).

  • radius_arcsec (float) – Cone search radius in arcseconds (default 3).

Returns:

dict or None – Photometry/astrometry for the nearest 2MASS source, or None if no match.

get_2mass_from_gaia(source_id, radius_arcsec=1.0)[source]

Return the 2MASS counterpart for a Gaia DR3 source.

Prefer ESA TAP: Gaia DR3 tmass_psc_xsc_* cross-match joined to gaiadr1.tmass_original_valid. If TAP is unavailable, fall back to the VizieR Gaia DR3 2MASS designation looked up in the 2MASS PSC (II/246), then a cone search around the Gaia position propagated to J2000.

The returned dict keys are twomass_id, tm_ra, tm_dec, j_m, j_msigcom, h_m, h_msigcom, ks_m, ks_msigcom; JHKs are Vega.

query_vizier(*, catalog, columns=None, center=None, radius_deg=None, constraints=None, column_filters=None, row_limit=50, max_rounds=None, description=None)[source]

Query one VizieR catalog, trying mirror servers in order with retry rounds.

Shared fallback layer for every VizieR query in the DRP, following the POTPyRI query_vizier_region / query_gaia_dr3_region pattern: clear the astroquery cache, walk vizier_mirrors() catching per-server errors, and repeat the whole list up to max_rounds times for transient failures. Each request uses a finite timeout (vizier_timeout()) so one unresponsive mirror cannot block the rest.

Exactly one of center (with radius_deg) or constraints must be given, selecting a cone search or a constraint query respectively.

Parameters:

  • catalog (str) – VizieR catalog identifier (e.g. 'I/355/gaiadr3').

  • columns (list of str, optional) – Columns to request; defaults to all columns (['**']).

  • center (astropy.coordinates.SkyCoord, optional) – Cone-search center.

  • radius_deg (float, optional) – Cone-search radius in degrees. Required with center.

  • constraints (dict, optional) – Column constraints for query_constraints (e.g. {'Source': '==12345'}).

  • column_filters (dict, optional) – VizieR server-side column filters (e.g. {'Gmag': '<8'}).

  • row_limit (int) – Maximum rows to return (-1 for unlimited).

  • max_rounds (int, optional) – Full passes over the mirror list. Defaults to VIZIER_MAX_ROUNDS_DEFAULT.

  • description (str, optional) – Short label for log messages; defaults to catalog.

Returns:

astropy.table.Table or None – First table of the response, or None if every mirror failed or no row matched.

vizier_mirrors()[source]

Return the VizieR servers to try, in order.

HISPEC_DRP_VIZIER_MIRRORS (comma-separated hostnames) overrides the built-in list, which lets a site with a local VizieR/Gaia DR3 mirror (e.g. Keck’s offline DR3) redirect every query in the DRP without code changes.
