ccf_oversample_nsp(pix_size_m_s, v_step_m_s)[source]

Number of CCF velocity samples per independent detector pixel.

Interpolated CCF(v) on a grid finer than Δv_pix reuses the same pixels, so Fisher / LM covariances that treat bins as i.i.d. must inflate σ_μ by √nsp with nsp = max(Δv_pix / Δv_grid, 1).

science_centroid_spec_err(spec, spec_err, spec_uncal=None, spec_uncal_err=None)[source]

Per-pixel σ for centroiding blaze-corrected (or native) flux.

A multiplicative fiberflat / blaze error is almost entirely amplitude, not line centroid. When L1 spec_uncal / spec_uncal_err are present, map the science-extract relative error onto spec:

σ = |spec| · |spec_uncal_err / spec_uncal|

(equivalent to σ_uncal / blaze). Fall back to spec_err where those arrays are missing or invalid.
