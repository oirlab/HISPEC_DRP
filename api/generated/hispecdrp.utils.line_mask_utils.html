Build a CCF-opt delta mask from an injected-RV=0 L2 via line-by-line stellar RV.

Two-step workflow (default use_single_line_builder=False):

  1. Run StellarRVPrimitive(algorithm="ccf_line_mask") on input_model with the seed mask and line-by-line windowing at ccf_input_velocity_m_s (typically 0). Set outlier_sigma very large (default 1e6) so chunk outlier rejection does not drop mask lines before aggregation.

  2. Pass the per-line RVCCF table to build_ccfopt_line_mask_from_rvccf_table(), which drops seed lines when any matching per-order calibration RV exceeds max_abs_rv_m_s (default CCFOPT_MAX_ABS_RV_M_S), then shifts each kept line λ' = λ × (1 + RV/c) and sets weights proportional to |Gaussian contrast|.

When use_single_line_builder=True, delegate to the slower per-line CCF path build_ccfopt_line_mask_from_l2_single_line_ccf() (gold-standard).

build_ccfopt_line_mask_from_l2_single_line_ccf(seed_mask_path, input_model, *, fiber=2, template_path=None, output_path=None, masks_directory=None, window_size_um=5.65e-05, window_line_by_line=True, v_half_window_m_s=20000.0, v_step_m_s=10.0, ccf_input_velocity_m_s=0.0, mask_ccf_pixel_interp_order=3, ccf_min_good_pixels=9, max_abs_rv_m_s=500.0, min_contrast=0.0, rezero_verify_abs_rv_m_s=0.001, max_rv_err_m_s=10.0, zb=0.0, max_seed_lines=None)[source]

Build a static rest-frame CCF-opt delta mask by zeroing single-line CCF bias.

For each seed line, run the same line-mask CCF path as StellarRVPrimitive(algorithm="ccf_line_mask") with line-by-line settings (CCFOPT_SINGLE_LINE_STELLAR_RV_KW, matching rv_recovery_sim.ipynb) but with a mask containing only that line. Shift the line center so the recovered RV equals the injected prior (ccf_input_velocity_m_s, typically 0):

λ' = λ_seed × (1 + (RV − ccf_input_velocity) / c)

The output .mas is a fixed rest-frame list (does not vary with bulk RV). Weights are proportional to |Gaussian CCF contrast| at the measured (pre-shift) CCF and are renormalized to sum to 1.

Lines are dropped when:

  • no valid chunk RV, |RV| above max_abs_rv_m_s, or contrast at/below min_contrast;

  • formal RV uncertainty ≥ max_rv_err_m_s (default 10 m/s);

  • after the λ shift, re-measured |RV − center| ≥ rezero_verify_abs_rv_m_s (default 0.001 m/s = 0.1 cm/s), or the re-measured uncertainty fails the same max_rv_err_m_s gate.

Parameters:

  • seed_mask_path – Packaged *.delta.mas seed.

  • input_model – Blaze-corrected L2-like model (WAVE_FIB* / SPEC_FIB*).

  • fiber – Fiber label matching the L2 attributes (default 2).

build_ccfopt_line_mask_from_rvccf_table(seed_mask_path, rvccf_table, *, template_path=None, output_path=None, masks_directory=None, match_half_m_s=5000.0, max_abs_rv_m_s=500.0, min_contrast=0.0)[source]

Build a CCF-opt delta mask from a line-by-line stellar-RV RVCCF table.

For each seed line, gather all RVCCF rows within match_half_m_s (any echelle order). Drop the seed when any matching row has |RV| > max_abs_rv_m_s (failed / aliased calibration in at least one order). Otherwise pick the nearest unused matching row, shift the mask center so that chunk’s measured RV becomes 0:

λ' = λ_seed × (1 + RV / c),

and set the weight proportional to |Gaussian contrast| of that chunk’s stored CCF. Weights are renormalized to sum to 1.

Parameters:

  • seed_mask_path – Path to the seed *.delta.mas (typically the packaged depth-weighted mask).

  • rvccf_table – Astropy table from StellarRVPrimitive with window_line_by_line=True (columns RV, WAVELENGTH, CCF, V_MIN, V_MAX, V_STEP).

  • template_path – Optional template path for metadata / default output naming.

  • output_path – Output .mas path (default <stem>.ccfopt.delta.mas under masks_directory).

  • masks_directory – Output .mas path (default <stem>.ccfopt.delta.mas under masks_directory).

  • match_half_m_s – Maximum |Δv| between seed λ and chunk WAVELENGTH for a match.

  • max_abs_rv_m_s – Drop a seed line when any matching RVCCF row (across orders) has |RV| above this gate (failed / aliased per-line calibration).

  • min_contrast – Drop lines whose absolute Gaussian contrast is at or below this floor.

Build a delta line mask aligned with e2e WAVE / RV truth (template centers).

Uses parabolic absorption centroids (same family as the sim-HDF line WAVE correction), a resolution-element deblend that keeps the deepest line in each blend, and continuum-normalized depth weights (sum → 1). No CCF-opt λ shifts — centers stay at template truth so CCF at injected RV=0 is unbiased when WAVE labels apparent line centers.

build_line_mask_from_template(template_path, *, wl_min_um=0.8, wl_max_um=3.0, min_continuum_normalized_depth=0.1, low_pass_width_multiplier=7.283985083415576, telluric_velocity_half_width_km_s=288.2674944075802, telluric_min_mean_transmission=0.0, transmission_file=None, continuum_filter_size=181, min_continuum_normalized_flux_floor=0.0001, apply_deblend=True, apply_telluric_filter=True, local_min_fn_window_half_width_nm=None, output_path=None, masks_directory=None)[source]

Detect lines in a template spectrum and write a filtered .mas mask.

Centroids come from detect_template_line_centers_gradient_um(). Each output row is (wavelength_vacuum_nm, weight) with no segment edges. Raw weights are continuum-normalized depth \(1 - F/F_c\) at each line center (interpolated), then are divided by their sum so output weights sum to 1.

Deblending (when apply_deblend) uses 0.5 * low_pass_width_multiplier * median(Δλ_nm) as the merge radius per line (deepest line kept in each cluster), where median(Δλ_nm) is from the sorted template grid. Pass apply_deblend=False / apply_telluric_filter=False (see RELAXED_TEMPLATE_MASK_BUILD_KW) to maximize line count.

Parameters:

  • template_path – Path to a supported template (BT-Settl .h5).

  • wl_min_um – Wavelength clip in vacuum microns before line search.

  • wl_max_um – Wavelength clip in vacuum microns before line search.

  • min_continuum_normalized_depth – Passed to detect_template_line_centers_gradient_um() and re-applied after interpolation to centers.

  • low_pass_width_multiplier – Scales the deblending radius vs. the template median wavelength step (nm). Ignored when apply_deblend is false.

  • telluric_velocity_half_width_km_s – Half-width in km/s for the telluric averaging interval (± this value). Ignored when apply_telluric_filter is false.

  • telluric_min_mean_transmission – Lines with mean transmission below this value are removed (telluric path only).

  • transmission_file – Two-column mktrans-style path (µm, transmission). Default: bundled data/atmosphere/mktrans_zm_10_10.dat.

  • continuum_filter_size – Odd-ish pixel size for the maximum-filter continuum envelope.

  • min_continuum_normalized_flux_floor – If not None, drop candidate lines whose local minimum of \(F/F_c\) (over ±local_min_fn_window_half_width_nm around the centroid) is below this value. Saturated cores have \(F/F_c \to 0\) and are skipped. Set None to keep saturated cores (relaxed seed).

  • apply_deblend – If false, skip nearest-neighbor deblend clustering (keep all depth-passing lines).

  • apply_telluric_filter – If false, skip the atmospheric-transmission gate.

  • local_min_fn_window_half_width_nm – Half-width of the wavelength interval (nm, vacuum) used for the local \(\min(F/F_c)\) test. If None, uses 5 × the template median step (nm).

  • output_path – Full path for the output .mas. If None, writes under masks_directory as <template_basename>.delta.mas (delta is the on-disk MASK_STYLE_DELTA layout; distinct stems per style match MaskLines.save()).

  • masks_directory – Default output directory (package data/masks if None).

Returns:

path_written, entries – Output file path and in-memory rows (wavelength_nm, weight).

compare_line_center_lists_um(centers_a, centers_b, *, match_tol_nm=0.05)[source]

Match two line-center lists (vacuum µm) within match_tol_nm (nanometers).

Returns counts and boolean masks over the sorted union of inputs for which centers fall in only A, only B, or both (matched pairs use greedy nearest-neighbor within tolerance on the merged sorted list — for diagnostics only).

Notes

Greedy matching: sort all centers from A and B with tags; sweep λ increasing, pairing unmatched A with next unmatched B if |Δλ| ≤ tol (in µm: tol_nm * 1e-3). Simpler approach: for each a in A, match if any b in B with |a-b| <= tol_um.

Returns:

dict – Keys: n_a, n_b, n_match, n_a_only, n_b_only, match_tol_nm, matched_pairs (list of (a_um, b_um)), centers_a_only_um, centers_b_only_um.

detect_template_line_centers_gradient_um(wave_um, flux, *, continuum_filter_size=181, min_continuum_normalized_depth=0.04, merge_min_sep_um=None)[source]

Absorption line centers (vacuum µm) from gradient zeros with positive curvature.

Intervals where the first derivative of flux w.r.t. λ (numpy.gradient) crosses zero are refined to a wavelength; the point is kept only if the second derivative of flux w.r.t. λ is positive (flux minimum, not maximum) and the usual continuum-normalized depth exceeds min_continuum_normalized_depth.

This is an alternative to chaining _local_minima_indices() with _parabolic_minimum_wavelength_um(); lists can be compared with compare_line_center_lists_um().

Parameters:

  • wave_um – Sorted vacuum-µm template grid (as from load_template_from_path).

  • flux – Sorted vacuum-µm template grid (as from load_template_from_path).

  • continuum_filter_size – Odd-ish size for _continuum_envelope() (depth definition).

  • min_continuum_normalized_depth – Minimum 1 - F/F_c at the interpolated stationary point.

  • merge_min_sep_um – Merge roots closer than this (µm). Default: 0.25 * median(Δλ) on the grid.

Returns:

np.ndarray – Centers in vacuum microns, sorted ascending.
