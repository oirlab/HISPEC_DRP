hispecdrp.primitives.stellar_rv.previews.stellar_rv_preview

Interactive previews for stellar radial-velocity products.

There are three preview surfaces:

  1. Default preview (create_stellar_rv_preview): two Plotly HTML embeds per save — (a) RV vs λ per fiber with its own mode bar; (b) CCF + residual per fiber (linked velocity axes within each fiber), second mode bar, slot dropdown. For ccf_line_mask with mask-overlay payload, the top row is the same spectrum/mask content as the standalone *_mask_overlay_debug_fib*.html (initial overlay velocity: finite ccf_input_velocity if set, else 0 m/s; chunk dropdown uses restyle). CCF slot dropdown aligns with the CCF legend (x). CCF panels overlay the Gaussian fit, bisector midpoints / wing chords when bisector_fit is present, and the final Gaussian RV.

  2. Spectrum + CCF overlay debug HTML (write_mask_overlay_debug_pages / write_template_overlay_debug_pages): one shared page implementation (ccf_spectrum_overlay_debug_html + embedded ccf_spectrum_overlay_unified.html.in) with an overlay_kind switch. Mask mode (ccf_line_mask): per-chunk spectrum (equal-µm bins from window_size_um / ccf_order_n_chunks_for_span(), or for window_line_by_line the symmetric window_size_um band about each predicted observed mask line at ccf_input_velocity / mask_line_window_spectrum_band_um()) with shifted mask segments and the pipeline mask CCF per chunk (same Numba grid as RVCCF; the overlay restores the raw weighted mask statistic when LINE_MASK_CCF_STORED_NEGATED_FROM_RAW is true in ccf_utils, matching the absorption-shaped CCF from the data). Template mode (ccf_stellar_template): same chrome, but the spectrum panel overplots the median-normalized rest-frame template Doppler-shifted onto each chunk’s wavelength samples; the CCF panel still uses the pipeline per-order template CCF from _ccf_preview_by_fiber (one curve per echelle order). Template CCF values are weighted covariances in data units and are often much smaller than 10⁻⁷; they are embedded with significant-figure rounding so fixed-decimal JSON does not zero the curve (the main Plotly preview passes float64 arrays and is unaffected). When the pipeline built _ccf_preview_by_fiber, mask mode can include ccf_v_m_s and ccf_err (quadrature of flux-error–propagated uncertainty on the mask-weighted mean and weighted line-to-line dispersion of F*SN; see _calc_mask_ccf_chunks_numba), interpolated onto the interactive CCF curve. Payload arrays are downsampled before embedding; limits come from env HISPEC_DRP_MASK_OVERLAY_SPECTRUM_MAX_POINTS / HISPEC_DRP_MASK_OVERLAY_CCF_MAX_POINTS (template crop length: HISPEC_DRP_TEMPLATE_OVERLAY_MAX_TEMPLATE_POINTS). Lagrange pixel-interpolation curve on the mask spectrum panel (same stencil as rv_per_chunks_line_mask / mask_ccf_pixel_interp_order) is always embedded in mask overlay debug HTML. The dense λ grid size is derived from the displayed spectrum point count: n_dense = 2 * mask_ccf_pixel_interp_order * N_specpoints (clamped to [24, 8192]), where N_specpoints is the number of points in the plotted blue spectrum trace.

Gaussian reference curves use fit_ccf_rv(); mask geometry uses ccf_utils (mask loaders).

Entry points. create_stellar_rv_preview() builds the standard multi-panel HTML; maybe_write_ccf_overlay_debug_html() dispatches from the primitive’s algorithm and overlay flags into the writers below; write_mask_overlay_debug_pages() / write_template_overlay_debug_pages() write the shared spectrum+CCF overlay pages (mask vs. template overlay); collect_mask_overlay_payload_for_primitive() and related helpers assemble mask/spectrum payloads from ccf_utils and the L2 model. Environment variables HISPEC_DRP_MASK_OVERLAY_* and HISPEC_DRP_SHOW_BSPEC_BTSETTL_PREVIEWS adjust downsampling and browser behavior (see in-file constants and call sites).

Notes

Plotly layout code is HISPEC DRP–original. For mask file format and upstream line lists, see hispecdrp/data/masks/README.md and spirou-ccf/KPF references in ccf_utils.

build_line_mask_chunk_wavelength_intervals_line_by_line(wave_um, mask_lines, *, v_center_m_s, zb, min_good_pixels=10)[source]

Build observed-wavelength chunks with one mask line per chunk (Voronoi cells in λ).

Mask rest wavelengths are mapped to the observed frame at v_center_m_s (same as doppler_shift_from_barycenter()). Distinct observed positions are sorted; each line defines one chunk whose wavelength window is the largest interval that (i) contains that predicted line λ, (ii) does not overlap neighboring chunks, and (iii) stays inside the pixel wavelength support [w_min, w_max] of wave_um. Neighbor boundaries are midpoints between adjacent predicted line wavelengths (1-D Voronoi cells). Spectrum outside the union of chunks is not analyzed.

Chunk center wavelengths are each line’s predicted observed λ.

The interval [wl_lo_um, wl_hi_um] is a 1-D Voronoi cell between neighbor lines (midpoint boundaries). It is not generally symmetric about the line’s predicted λ unless neighbor spacings happen to match.

Parameters:

  • wave_um – 1-D wavelength samples (µm) for the order.

  • mask_lines – Mask lines for the run.

  • v_center_m_s – Typically ccf_input_velocity (m/s).

combine_rv_estimates_median_mad_weighted(rvs, rv_errs, outlier_sigma=4.0, *, center_m_s=None, rv_err_inflation=3.5)[source]

Error-aware robust rejection, inverse-variance mean, and IVW uncertainty.

Outlier rejection uses the uninflated per-chunk rv_errs with combine_rvs_median_mad() (|Δ| <= outlier_sigma * max(MAD, σ_i)). Per-chunk rv_errs are scaled by rv_err_inflation only for IVW weights (default 3.5) so the mean is not dominated by underdispersed formal σ. The reported rv_std is \(\max(\sigma_{\mathrm{IVW}},\,\mathrm{MAD}/\sqrt{N})\) of the inliers: photon-weighted IVW when it is honest, and the empirical line scatter when formal σ are optimistic or systematics dominate. As per-chunk σ → 0 (infinite S/N), this converges to MAD/√N. If the median formal σ is >10⁶× the inlier MAD (broken Hessian), IVW is discarded and MAD/√N is reported. Inflated IVW SE and empirical MAD/√N are returned as rv_std_internal and scatter_se for diagnostics.

combine_rvs_median_mad(rvs, rv_errs, outlier_sigma=4.0, *, center_m_s=None)[source]

Error-aware robust outlier mask on per-chunk RVs.

Chunks with finite rvs and positive rv_errs set the rejection center (sample median, or center_m_s when finite) and the ensemble MAD. A chunk is kept when

|RV − center| <= outlier_sigma * max(MAD, σ_i)

so points that agree within the MAD are never rejected, while points that are both outside the MAD envelope and inconsistent with their own formal σ_i are rejected. Invalid chunks are marked not inlier.

fit_ccf_rv(v_grid_m_s, ccf, v_step_m_s, n_good=None, return_params=False, *, ccf_err=None, mask_method=None, config=None, vel_span_m_s_per_pixel=None, two_pass=True, max_velocity_samples=8192, ccf_line_mask_stored_negated=None, fit_ccf_baseline_free=None, line_mask_line_window_by_line=None, gaussian_seed_mean_m_s=None)[source]

Fit a Gaussian plus constant baseline to a precomputed CCF and return RV ± error in m s⁻¹.

Uses a robust emission/absorption profile guess, Gaussian1D plus Const1D on the CCF in a sliding velocity window (values are scaled to ~unit magnitude before LM; RV parameters are unchanged). By default the constant baseline is fixed to _ccf_background_sigma_clipped_median() of the CCF samples in each fit window (not a free LM parameter). When fit_ccf_baseline_free=True, or when line_mask_line_window_by_line is true (narrow line-mask line-by-line grids) and ccf_line_mask_stored_negated is not true, the baseline is a free Const1D term fit jointly with the Gaussian, and pass half-widths are capped to a fraction of the available velocity span so the fit is not dominated by an artificial “global median” baseline across the whole short profile. The same half-width caps apply when ccf_line_mask_stored_negated is true (mask-line CCF), so fixed-baseline fits on short grids do not inherit multi-hundred-km pass windows. One or two Levenberg–Marquardt passes each use a wide velocity window (see CCFFitConfig) to stabilize the Gaussian amplitude and width. Within each window the fitter runs unclipped χ² passes on the full sample (repeated LM with levmar_maxiter), then sigma-clipping refinement with relaxed thresholds on the first clipping rounds. Formal uncertainty may use a KPF-inspired ccf_error scaling when plausible, else covariance from the fitter, else a σ/√n fallback.

Parameters:

  • v_grid_m_s (np.ndarray) – Velocity samples (m s⁻¹), usually sorted (uniform broad or centered window).

  • ccf (np.ndarray) – CCF values on the same grid.

  • v_step_m_s (float) – Effective finest velocity spacing (m s⁻¹) for plausibility checks and n_sp scaling — typically effective_ccf_v_step_for_fit() on v_grid_m_s.

  • n_good (int or None, optional) – Number of good spectral pixels in the chunk (for fallback error scaling).

  • return_params (bool, optional) – If True, return (rv, rv_err, params_dict, diag_dict); else (rv, rv_err).

  • mask_method (str or None, optional) – If in CCFFitConfig.cal_mask_methods, use absorption-style calibration peak logic.

  • config (CCFFitConfig or None, optional) – Override fit windows and thresholds.

  • vel_span_m_s_per_pixel (float or None, optional) – Spectral sampling scale passed into error heuristics.

  • two_pass (bool, optional) – If True (default), run a second fit narrowed around the first mean.

  • max_velocity_samples (int or None, optional) – When the input grid has more than this many finite samples, apply uniform stride subsampling for the Gaussian fit only (default 8192). Set None to always use the full grid. Does not change stored CCF arrays elsewhere — only speeds LM fitting on very long line-mask broad scans.

  • ccf_err (np.ndarray or None, optional) – Per-sample CCF uncertainty (same shape as ccf). When finite and predominantly positive, Levenberg–Marquardt fits use weights = 1/ccf_err² on the raw CCF samples in each pass window.

  • ccf_line_mask_stored_negated (bool or None, optional) – When not None, recorded in the diagnostics dict (when return_params is True) as "ccf_line_mask_stored_negated". Use True for mask-line CCF rows produced by rv_per_chunks_line_mask() / run_ccf_line_mask_for_fiber() (stored convention: negated from the raw weighted mask statistic so the peak is near the true RV). When True, the fitter does not use the data-driven emission/absorption heuristic: it assumes a peak-up line (positive Gaussian1D amplitude in scaled units, seed at the discrete maximum) and sets Gaussian1D.amplitude lower bound to 0 so LM cannot flip to a spurious negative-lobe solution on flat mask CCFs. None (default) omits the key — caller convention unknown.

  • fit_ccf_baseline_free (bool or None, optional) – When True, fit the CCF constant baseline in LM (do not fix Const1D). When None (default), use _line_mask_ccf_fit_free_baseline_requested() with line_mask_line_window_by_line to decide.

  • line_mask_line_window_by_line (bool or None, optional) – Line-mask line-by-line chunking flag (same meaning as window_line_by_line on the primitive). When fit_ccf_baseline_free is None and this is true, free-baseline mode is enabled automatically unless ccf_line_mask_stored_negated is true (see _line_mask_ccf_fit_free_baseline_requested()).

  • gaussian_seed_mean_m_s (float or None, optional) – When ccf_line_mask_stored_negated is true and this lies on the velocity grid, the discrete peak seed uses argmax(CCF) restricted to samples within a local window around this value (typically ccf_input_velocity), instead of the global maximum on the full grid. That avoids spurious seeds on stacked mean CCFs and aligns pass-1 with the injected search center.

Returns:

tuple – If return_params is False: (rv_ms, rv_err_ms). If True: (rv_ms, rv_err_ms, params, diag) with fitted Gaussian parameters and diagnostic metadata.

Notes

Design parallels public KPF PRV CCF-fitting ideas; see module References. When both the gradient-based CCF error and the Levenberg–Marquardt covariance on the Gaussian mean pass plausibility checks, CCFFitConfig field rv_err_cov_combine chooses ``min`` (historic) or ``max`` (more conservative; default).

Optional parametric bootstrap (rv_err_bootstrap_samples > 0): repeatedly add i.i.d. N(0, ccf_err) noise to the final-window CCF samples, refit the weighted Gaussian, and take the sample standard deviation of fitted means (m/s). The reported rv_err is at least that bootstrap scatter when bootstrap runs (still diagonal / uncorrelated noise; see Notes).

Self-consistency of ``ccf_err`` → ``rv_err`` (what is *not* done).

  • ccf_err is used only as diagonal inverse-variance weights 1/σ² on the raw CCF samples inside each fit window (Gaussian + constant model). For the line-mask primitive (ccf_line_mask), those σ come from the weighted SD of per-line \(F\,\mathrm{SN}\) about the chunk CCF, then combined across chunks as a standard error of the mean; this is not a full propagation from pixel flux errors, and bin-to-bin correlations in \(v\) are ignored.

  • The Levenberg–Marquardt covariance on the Gaussian mean (when returned by Astropy) is a local linearization error for the weighted nonlinear fit; it does not add systematic terms from model mismatch (true line profile ≠ Gaussian).

  • The gradient-based _gradient_ccf_err_km branch uses gradients of the raw CCF (√|CCF| scaling) and does not use ccf_err. It returns 0 if any CCF sample in the fit window is negative, so for strongly absorption-shaped curves the gradient branch may be inactive and rv_err relies on covariance or fallbacks. With rv_err_cov_combine="min", ``min(gradient, cov)`` can still yield an optimistically small rv_err; default "max" is more conservative.

  • If the LM Gaussian width collapses toward zero, the formal covariance on the mean can reach ~1e-16 m/s while still passing _ok_err; such fits set diag["lm_gaussian_width_plausible"]=False, drop the covariance branch, and combine rv_err with _rv_err_slope_propagation_m_s() (CCF + ccf_err) and a widened σ/√n fallback using v_step.

  • When the LevMar covariance is used for rv_err, slope propagation is still computed for diag["rv_err_slope_propagation_m_s"] but is not forced as a minimum on rv_err (no 200 km/s-style floor from max(rv_err, σ_slope)).
