Tunables for fit_ccf_rv_bisector() (traditional CCF bisector RV).

Follows the NEID-DRP bisector construction (percentile cuts through the CCF in velocity space; see NEID algorithms § CCF Bisector Calculation). Radial velocity and its uncertainty are a weighted mean of bisector midpoints \((v_\mathrm{left}+v_\mathrm{right})/2\) at multiple depth percentiles: with per-cut midpoint uncertainties \(e_i\) and weights \(w_i\),

\[\hat{v} = \frac{\sum_i w_i v_i}{\sum_i w_i},\qquad \sigma_{\hat{v}} = \frac{\sum_i w_i e_i}{\sum_i w_i}.\]

(The uncertainty is the weighted average of the cut uncertainties, not an independent-measurement reduction of those errors.) Cut weights are the core performance weight only; per-cut \(e_i\) comes from CCF-error propagation when informative, otherwise from the smooth-profile discretization estimate.

_calc_mask_ccf_chunks_numba(left_edges_2d, right_edges_2d, s_use_2d, e_use_2d, sn_2d, n_pix_arr, v_grid_m_s, zb, line_lambda_rest_2d, line_left_rest_2d, line_right_rest_2d, line_w_2d, n_line_arr, compute_line_std, pixel_interp_order, tophat_segment_samples)[source]

Chunk-batched mask CCF(v) with parallelism over chunks.

Delta-line model: each mask line is a rest wavelength \(\lambda_{\rm rest}\). At trial velocity \(v\), the observed wavelength is \(\lambda_{\rm obs} = \lambda_{\rm rest}\,(1+v/c)/(1+z_b)\).

Tophat segment model (finite width): each mask entry has rest edges \([\lambda_{\rm lo},\lambda_{\rm hi}]\). At trial velocity the observed segment is shifted by the same factor as above. The segment’s contribution is approximated by averaging \(F\cdot\mathrm{SN}\) over tophat_segment_samples uniformly spaced points inside the shifted segment.

For each velocity, let \(x_j = F_j\,\mathrm{SN}_j\) at each contributing line (interpolated on pixel centers). Accumulate \(\sum_j w_j x_j\) and \(\sum_j w_j x_j^2\) over lines whose shifted \(\lambda_{\rm obs}\) lies in the chunk with finite \(F\) and \(\mathrm{SN}\). The CCF is the weighted mean \(\mathrm{CCF}(v)=\sum_j w_j x_j\,/\,\sum_j w_j\).

Flux errors: e_use_2d holds per-pixel flux \(\sigma\) on the chunk grid. The mask statistic is linear in pixel values \(G_m\) (Lanczos / linear interpolation of flux per line, \(\mathrm{SN}_j\) treated as exact on the stencil): \(C = \sum_m c_m G_m\) with \(c_m = \sum_j (w_j/W)\,\mathrm{SN}_j\,L^{(j)}_{m}\) where \(W=\sum_j w_j\) and \(L^{(j)}_{m}\) is the interpolator weight of pixel \(m\) for line \(j\) (zero outside that line’s stencil). Under independent pixel noise, \(\sigma_{\mathrm{meas}}^2 = \sum_m c_m^2 \sigma_m^2\). This co-adds lines that share stencil pixels and replaces the earlier \(\sum_j w_j^2\mathrm{Var}(F_j)/W^2\) independent-line sum, which inflated \(\sigma_{\mathrm{meas}}\) when many lines reused the same pixels.

The systematic / excess line-to-line component is the usual weighted dispersion of \(x_j\) about \(C\):

\[\sigma_{\mathrm{line}}^2 = \max\left(0,\; \frac{\sum_j w_j x_j^2}{\sum_j w_j} - C^2\right)\,.\]

When compute_line_std is True, the second output is the flux-propagated measurement uncertainty \(\sigma_{\mathrm{meas}}\) (independent pixel noise through the interpolator stencil). A line-to-line flux scatter \(\sigma_{\mathrm{line}}\) is still accumulated internally but is not added in quadrature: that term is a depth-dispersion floor, not jitter on the CCF centroid, and would freeze \(\sigma_\mu\) at the LSF width even at infinite S/N.

The third output stores the same \(\sigma_{\mathrm{meas}}\) (nan when unavailable).

Input arrays are padded to fixed widths; n_pix_arr and n_line_arr give valid lengths for each chunk row.

Uses both a fraction of the detrended peak-to-valley span and a fraction of the positive peak above the median-detrended baseline: span alone can be noise-dominated on narrow mask-CCF grids, leaving a tiny floor that still allows an effectively flat Gaussian.

Fit a Gaussian plus constant baseline to a precomputed CCF and return RV ± error in m s⁻¹.

Uses a robust emission/absorption profile guess, Gaussian1D plus Const1D on the CCF in a sliding velocity window (values are scaled to ~unit magnitude before LM; RV parameters are unchanged). By default the constant baseline is fixed to _ccf_background_sigma_clipped_median() of the CCF samples in each fit window (not a free LM parameter). When fit_ccf_baseline_free=True, or when line_mask_line_window_by_line is true (narrow line-mask line-by-line grids) and ccf_line_mask_stored_negated is not true, the baseline is a free Const1D term fit jointly with the Gaussian, and pass half-widths are capped to a fraction of the available velocity span so the fit is not dominated by an artificial “global median” baseline across the whole short profile. The same half-width caps apply when ccf_line_mask_stored_negated is true (mask-line CCF), so fixed-baseline fits on short grids do not inherit multi-hundred-km pass windows. One or two Levenberg–Marquardt passes each use a wide velocity window (see CCFFitConfig) to stabilize the Gaussian amplitude and width. Within each window the fitter runs unclipped χ² passes on the full sample (repeated LM with levmar_maxiter), then sigma-clipping refinement with relaxed thresholds on the first clipping rounds. Notes

Design parallels public KPF PRV CCF-fitting ideas; see module References. When both the gradient-based CCF error and the Levenberg–Marquardt covariance on the Gaussian mean pass plausibility checks, CCFFitConfig field rv_err_cov_combine chooses ``min`` (historic) or ``max`` (more conservative; default).

Optional parametric bootstrap (rv_err_bootstrap_samples > 0): repeatedly add i.i.d. N(0, ccf_err) noise to the final-window CCF samples, refit the weighted Gaussian, and take the sample standard deviation of fitted means (m/s). The reported rv_err is at least that bootstrap scatter when bootstrap runs (still diagonal / uncorrelated noise; see Notes).

Self-consistency of ``ccf_err`` → ``rv_err`` (what is *not* done).

  • ccf_err is used only as diagonal inverse-variance weights 1/σ² on the raw CCF samples inside each fit window (Gaussian + constant model). For the line-mask primitive (ccf_line_mask), those σ come from the weighted SD of per-line \(F\,\mathrm{SN}\) about the chunk CCF, then combined across chunks as a standard error of the mean; this is not a full propagation from pixel flux errors, and bin-to-bin correlations in \(v\) are ignored.

  • The Levenberg–Marquardt covariance on the Gaussian mean (when returned by Astropy) is a local linearization error for the weighted nonlinear fit; it does not add systematic terms from model mismatch (true line profile ≠ Gaussian).

  • The gradient-based _gradient_ccf_err_km branch uses gradients of the raw CCF (√|CCF| scaling) and does not use ccf_err. It returns 0 if any CCF sample in the fit window is negative, so for strongly absorption-shaped curves the gradient branch may be inactive and rv_err relies on covariance or fallbacks. With rv_err_cov_combine="min", ``min(gradient, cov)`` can still yield an optimistically small rv_err; default "max" is more conservative.

  • If the LM Gaussian width collapses toward zero, the formal covariance on the mean can reach ~1e-16 m/s while still passing _ok_err; such fits set diag["lm_gaussian_width_plausible"]=False, drop the covariance branch, and combine rv_err with _rv_err_slope_propagation_m_s() (CCF + ccf_err) and a widened σ/√n fallback using v_step.

  • When the LevMar covariance is used for rv_err, slope propagation is still computed for diag["rv_err_slope_propagation_m_s"] but is not forced as a minimum on rv_err (no 200 km/s-style floor from max(rv_err, σ_slope)).

Compute per-chunk RVs and optional CCF stacks for one echelle order.

By default splits the order into equal-wavelength bins (count from ccf_order_n_chunks_for_span() given the order span and window_size_um), then computes chunk CCF rows in one Numba batch via _calc_mask_ccf_chunks_numba() (parallel over chunks; delta-line interpolation at each Doppler-shifted rest wavelength), followed by a Numba chunk-parallel discrete-peak seed. Chunks on an echelle row are iterated longest λ first (descending chunk-center wavelength, red → blue along the row), so downstream RVCCF rows and mask-overlay segments follow the same ordering as ascending echelle order in the exposure. RV extraction assumes a fixed absorption-line convention for all chunks and orders (fit on -CCF, not data-driven emission/absorption guessing). Peak selection uses a 5-point smoothed CCF and a combined score (wide-window integrated excess above the global median times √prominence) over strict local maxima—favoring the broad, physically coherent peak at the true RV over narrow spurious maxima. A fast Numba estimate is computed first; then chunk RVs are updated with a Numba-parallel Gaussian+fixed-baseline LM centroid (fit_ccf_rv_rows_numba(), same peak-up / fixed-baseline convention as fit_ccf_rv() for line-mask rows). If the Gaussian path does not return a finite RV, the Numba seed is kept. Returns flattened lists of chunk centers and RVs.

ccf_2d is the weight-normalized mask CCF used for RV extraction and stacking; ccf_preview_2d holds the same rows before the per-chunk sign flip applied for ccf_2d (both match the physical weighted CCF up to that convention).
