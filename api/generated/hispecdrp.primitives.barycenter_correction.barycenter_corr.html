  • epoch (float) – Epoch of the input coordinates (e.g., 2000.0).

berv_m_s_to_ccf_zb(berv_m_s)[source]

Convert BARYCORR BERV (m/s) to the CCF barycentric factor \(z_b\).

Matches doppler_shift_from_barycenter() where zb1 = 1 + z_b and trial velocity enters as v / c.

calc_barycenter_corrections(mjd_utc, star_data, observatory, zmeas=0.0)[source]

Calculate the barycenter corrections for the input data using barycorrpy.

Parameters:

  • mjd_utc (float | Sequence[float]) – Modified Julian Date in UTC.

  • star_data (BarycorrpyStarData) – Stellar data required for barycenter correction calculation.

  • observatory (str | EarthLocation) – Observatory name or EarthLocation object for the observation.

  • zmeas (float, optional) – Measured redshift of the target, relevant for relativistic corrections. Default is 0.

Returns:

  • mbjd (float) – Modified Barycentric Julian Date.

  • vel_bc (float) – Barycentric Earth Radial Velocity correction in m/s (barycorrpy convention).

read_berv_m_s_from_model(input_model, fiber)[source]

Return BERV (m/s) from BARYCORR_FIB#, or None when unavailable.

read_berv_m_s_uniform_from_model(input_model)[source]

Return exposure BERV (m/s) from the first populated BARYCORR_FIB# table.

HISPEC barycentric corrections are not resolved per fiber at the precision relevant for CCF; one value applies to all fibers on the exposure.

resolve_ccf_zb(input_model, *, ccf_zb=0.0)[source]

Resolve the exposure CCF barycentric factor from BARYCORR.

When any BARYCORR_FIB# table is populated, BERV (m/s) is converted to dimensionless \(z_b\) and applied uniformly to all fibers. Otherwise returns ccf_zb.
