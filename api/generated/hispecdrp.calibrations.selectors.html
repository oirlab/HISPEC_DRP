class FiberFlatSelector(origin='ANY', cal_version='LATEST', master_cal=None, **kwargs)[source]

Bases: HISPECCalibrationSelector

Selector for fiber-flat calibration files.

Prefers flats whose object_fiber{N} is WHITELIGHT for every science fiber on the input (object_fiber{N} == SCIENCE), so a fiber-2-only flat is not chosen for a fiber-1 / fiber-3 exposure on the same night.

static _science_fibers_from_input(input)[source]

Resolve SCIENCE fibers from a DataModel or bare meta.

HISPECCalibrationStore.select_and_get_calibration passes input.meta into selector.select, so input is often already a MetaModel (no nested .meta).

Selector for nonlinear correction calibration files.

Calibration Type: nonlin

Selection Logic:

  • Match instrument era

  • Match spectrograph

  • Require master calibration

  • Closest in observation time

  • Prefer sim-matched nonlin (meta.note / sim_matched_nonlin) when present among candidates, so UTR sims that set nonlin_coeffs do not silently pick a competing KOA master

class WavelengthSolutionSelector(cal_type='lfc_wavesol', fallback_cal_types=None)[source]

Bases: HISPECCalibrationSelector

Selector for wavelength solution calibration files.

Calibration Type: Configurable (default: lfc_wavesol)

Selection Logic:

  • Match instrument era

  • Match spectrograph

  • Closest in observation time

  • Prefer packaged sim-HDF line-ZP WAVE (meta.note / sim_hdf_wavesol.line_zp) when present among candidates, so simulation Stage 1 does not silently pick a competing geometric lfc_wavesol

Parameters:

  • cal_type (str, optional) – The type of wavelength calibration to select. Default: lfc_wavesol

  • fallback_cal_type (str | None, optional) – The type of wavelength calibration to select as a fallback. Default: None
