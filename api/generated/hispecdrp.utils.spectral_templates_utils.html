hispecdrp.utils.spectral_templates_utils

hispecdrp.utils.spectral_templates_utils

Spectral template I/O and preparation for stellar CCF.

Loads BT-Settl-style HDF5 spectra (lte*.h5), resolves paths, converts air ↔ vacuum wavelengths (see air_wavelength_nm_to_vacuum_nm() and vacuum_wavelength_nm_to_air_nm()), normalizes to 2MASS AB magnitudes using profiles from the SVO Filter Profile Service, and builds \((\ln\lambda, \mathrm{flux})\) grids for StellarRVPrimitive.

Submodules and data

Bundled templates and format notes live under hispecdrp/data/templates/ (see that directory’s README.md for BT-Settl CIFIST, air wavelengths, and HDF5 layout).

Notes

  • BT-Settl model grids: cite Allard et al. / BT-Settl papers for the atmosphere data, not HISPEC DRP.

  • 2MASS filter curves prefer bundled Cohen/IPAC RSR files under hispecdrp/data/filters/; SVO (SVO_FILTER_URL) is only tried if those are missing.

  • Air–vacuum conversions use a dry-air refractivity polynomial in _edlen_refractivity_ppm_nm() (SPIROU / Morton-style Cauchy form); refractivity is evaluated at the air wavelength, so the inverse uses fixed-point iteration.

  • Wavelength convention for loaded templates matches vacuum L2 axes when wavelengths_are_air=True in load_btsettl_spectrum().

References

  • BT-Settl spectral grid (project home / papers; cite per your file version): http://perso.ens-lyon.fr/france.allard/

  • SVO Filter Profile Service: https://svo2.cab.inta-csic.es/theory/fps3/

  • spirou-ccf (spectral order / CCF context): https://github.com/edermartioli/spirou-ccf/blob/main/spiroulib.py

air_wavelength_nm_to_vacuum_nm(air_wavelength_nm, *, air_density=1.0)[source]

Convert air wavelength to vacuum wavelength (nanometers).

Uses the standard mapping

\[\lambda_\mathrm{vac} = \lambda_\mathrm{air}\, \bigl(1 + 10^{-6} N(\lambda_\mathrm{air})\bigr),\]

where \(N\) is _edlen_refractivity_ppm_nm() evaluated at \(\lambda_\mathrm{air}\).

Parameters:

  • air_wavelength_nm (array_like) – Wavelength(s) in nanometers (air).

  • air_density (float, optional) – Passed to _edlen_refractivity_ppm_nm().

Returns:

np.ndarray – Vacuum wavelength(s) in nanometers (same shape as broadcast input).

etalon_line_list(fsr, wavelength_range, n_cavity, wavelength_meas, finesse_meas, peak_trans_meas)[source]

Generate an etalon resonance line list over a wavelength range.

The resonance wavelengths are calculated using the ideal Fabry–Pérot etalon resonance condition,

lambda_m = 2 * n * d / m,

where m is the integer resonance order and d is the cavity length. The cavity length is inferred from the supplied free spectral range (FSR) using

FSR = c / (2 * n * d).

The measured finesse and peak transmission are linearly interpolated onto the calculated resonance wavelengths.

This function calculates only the resonance positions; it does not evaluate the full Airy/Fabry–Pérot transmission profile between resonances.

Parameters:

  • fsr (astropy.units.Quantity) – Free spectral range of the etalon. Converted internally to Hz.

  • wavelength_range (tuple[astropy.units.Quantity, astropy.units.Quantity]) – Minimum and maximum wavelengths to include. Converted internally to nm for calculating the resonance orders.

  • n_cavity (float) – Refractive index inside the etalon cavity.

  • wavelength_meas (astropy.units.Quantity) – Wavelengths at which the finesse and peak transmission were measured. These values should be sorted in increasing wavelength for use with numpy.interp.

  • finesse_meas (numpy.ndarray) – Measured finesse values corresponding to wavelength_meas.

  • peak_trans_meas (numpy.ndarray) – Measured peak transmission values corresponding to wavelength_meas.

Returns:

  • order (numpy.ndarray) – Integer Fabry–Pérot resonance orders corresponding to each line.

  • wavelength (astropy.units.Quantity) – Resonance wavelengths, returned in microns.

  • finesse (numpy.ndarray) – Finesse interpolated from finesse_meas at each resonance wavelength.

  • transmission (numpy.ndarray) – Peak transmission interpolated from peak_trans_meas at each resonance wavelength.

Notes

The resonance positions assume an ideal, plane-parallel Fabry–Pérot etalon with normal incidence. Dispersion in the cavity refractive index is not included because n_cavity is treated as a constant.

numpy.interp uses the endpoint values when a calculated resonance lies outside the range of wavelength_meas. Therefore, the measured wavelength range should generally cover the requested resonance range if extrapolation by constant endpoint values is not desired.

load_btsettl_spectrum(filepath, wl_min_um=0.8, wl_max_um=3.0, mag_ab=None, filter_band=None, *, wavelengths_are_air=True)[source]

Load wavelength and flux from a BT-Settl spectrum HDF5 file.

The file is expected to have wavelength (in Angstrom) and flux (in 1e-23 erg/cm^2/s/Angstrom) datasets. SVO BT-Settl (CIFIST) HDF5 files also store model parameters on the root attributes temperature (K), surface_gravity (log g cgs), and metallicity; read them with h5py if needed (see hispecdrp/data/templates/README.md).

By default (wavelengths_are_air=True) the HDF5 wavelength grid is treated as air Angstrom and converted to vacuum microns before return, so the template matches vacuum wavelength axes (e.g. HISPEC L2 wave_*, SPIROU-style masks in vacuum nm). Set wavelengths_are_air=False if the file is already on a vacuum grid.

If mag_ab and filter_band are set, the spectrum is normalized to the given AB magnitude in the corresponding 2MASS filter (J, H, or K). The 2MASS profile is fetched from the SVO Filter Profile Service.

Parameters:

  • filepath (str) – Path to the .h5 file (e.g. lte025.0-5.5-0.0a+0.0.BT-Settl.spec.7.h5).

  • wl_min_um (float, optional) – Minimum wavelength in microns. Default is 0.8.

  • wl_max_um (float, optional) – Maximum wavelength in microns. Default is 3.0.

  • mag_ab (float or None, optional) – If set with filter_band, normalize the spectrum to this AB magnitude in that band. Default is None.

  • filter_band (str or None, optional) – One of ‘J’, ‘H’, ‘K’. Used with mag_ab to normalize. Default is None.

  • wavelengths_are_air (bool, optional) – If True (default), convert stored wavelengths from air to vacuum before applying wl_min_um / wl_max_um (interpreted as vacuum microns).

Returns:

  • wavelength (astropy.units.Quantity) – Wavelength array in micron (vacuum when wavelengths_are_air is True).

  • flux (astropy.units.Quantity) – Flux density in erg/s/cm^2/Angstrom (same as file).

Raises:

ImportError – If h5py is not installed.

References

BT-Settl atmosphere models; cite the grid publication appropriate to your file. See hispecdrp/data/templates/README.md for CIFIST / SVO air-wavelength notes.

resolve_stellar_template_to_log_micron(template_path, template_wavelength, template_flux, *, wl_min_um=0.8, wl_max_um=3.0)[source]

Resolve a stellar template to (ln λ, flux) with λ in microns, for CCF.

If template_path is set and either wavelength or flux array is missing, loads from disk using load_template_from_path() over [wl_min_um, wl_max_um] (a broad range; finer clipping may be done per fiber/order downstream).

If both template_wavelength and template_flux are provided (and not overridden by a path-only load), they are validated, sorted in wavelength, and converted to natural log wavelength.

Parameters:

  • template_path (str or None) – Path to BT-Settl (or supported) file.

  • template_wavelength – Optional wavelength (microns, linear) and flux arrays.

  • template_flux – Optional wavelength (microns, linear) and flux arrays.

Returns:

  • template_ln (np.ndarray or None) – \(\ln(\lambda)\) with \(\lambda\) in microns, or None.

  • template_flux (np.ndarray or None) – Flux aligned with template_ln, or None.

Notes

On load failure from template_path, logs an exception and returns (None, None) without re-raising.

vacuum_wavelength_nm_to_air_nm(vacuum_wavelength_nm, *, air_density=1.0, max_iter=12, rtol=1e-14)[source]

Convert vacuum wavelength to air wavelength (nanometers).

The forward relation air_wavelength_nm_to_vacuum_nm() depends on refractivity evaluated at air wavelength, so the inverse is not a single closed-form division by a factor evaluated at vacuum λ. This function solves

\[\lambda_\mathrm{vac} = \lambda_\mathrm{air}\, \bigl(1 + 10^{-6} N(\lambda_\mathrm{air})\bigr)\]

by fixed-point iteration

\[\lambda_\mathrm{air}^{(k+1)} = \frac{\lambda_\mathrm{vac}} {1 + 10^{-6} N\bigl(\lambda_\mathrm{air}^{(k)}\bigr)},\]

starting from \(\lambda_\mathrm{air}^{(0)} = \lambda_\mathrm{vac}\). Convergence is rapid because \(10^{-6}N\) is \(\mathcal{O}(10^{-4})\).

Parameters:

  • vacuum_wavelength_nm (array_like) – Wavelength(s) in nanometers (vacuum).

  • air_density (float, optional) – Passed to _edlen_refractivity_ppm_nm().

  • max_iter (int, optional) – Maximum iterations (default 12 is ample for double precision).

  • rtol (float, optional) – Stop when all finite elements satisfy abs(air_new - air) <= rtol * max(abs(air), 1e-30).

Returns:

np.ndarray – Air wavelength(s) in nanometers. Non-finite or non-positive vacuum inputs are mapped to NaN.

Raises:

ValueError – If max_iter < 1.

See also

air_wavelength_nm_to_vacuum_nm

Forward air → vacuum.

Notes

Round-trip air → vac → air matches the original air grid within ~machine precision for typical NIR wavelengths when using the same air_density.
