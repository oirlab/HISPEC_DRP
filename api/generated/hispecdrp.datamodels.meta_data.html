get_instrument_config(input=None, instrument_name=None)[source]

Get the instrument configuration class from either a FITS filename or an HDUList.

Parameters:

  • input (str or fits.HDUList, optional) – Either a FITS filename path or an already-opened HDUList object. The INSTRUME keyword will be read from the primary header.

  • instrument_name (str, optional) – The instrument name. If provided, this will be used instead of reading the instrument name from the FITS header.

Returns:

config_class (type) – The instrument config class if found.

Raises:

  • TypeError – If input is neither a string nor an HDUList.

  • ValueError – If no INSTRUME keyword is found in the header, or if the instrument config is not found in INSTRUMENT_CONFIGS.
